## 4. Gewichtete Nutzwertanalyse

Bewertungsskala:

1 = Sehr schwach  
2 = Schwach  
3 = Ausreichend  
4 = Gut  
5 = Sehr gut

| Kriterium                        |   Gewicht | Idee 1 | Idee 2 | Idee 3 |
| -------------------------------- | --------: | -----: | -----: | -----: |
| Technische Machbarkeit           |      30 % |        |        |        |
| Interdisziplinäre Zusammenarbeit |      25 % |        |        |        |
| Praxisrelevanz                   |      20 % |        |        |        |
| Erwarteter Nutzen                |      15 % |        |        |        |
| Innovationspotenzial             |      10 % |        |        |        |
| **Total**                        | **100 %** |        |        |        |

Berechnung je Idee:

Gesamtpunktzahl =
Summe(Bewertung × Gewichtung) / 100

Möglicher Wertebereich: 1.0 bis 5.0.

Die Gewichte sind Vorschläge und müssen vor der
Bewertung gemeinsam bestätigt werden.

## Projektübersicht

Softwareentwickler und drei Systemtechniker
gemeinsam eine praxisorientierte IoT-Lösung.

Das Projekt umfasst die Ideenfindung, Konzeption,
Realisierung, Einführung und Qualitätssicherung.
